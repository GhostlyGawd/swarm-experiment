# Executable declaration profile V9

V9 adds explicit `body: null` support to the executable TypeScript, Python and Rust projections. An unsynthesized declaration keeps its exact AST identity, types and contract in the visible source. Calling it raises `unsynthesized_body` before any function body can fabricate a result or run an effect. An exact-address imported declaration retains the same behavior through the bundle/parser. The [tests](../../../../test/projection/declarations.test.ts) compile and execute all three target languages and reject altered trap scaffolding and runtime bytes.

V8 and earlier formats are unchanged. A detached comparison of a V8 generic/nested-import fixture at source `a69ae6e` and V9 source `80a37c9` produced identical source, runtime and dependency SHA-256 values for all three targets; [before](../../../../docs/implementation/v4/evidence/integration-80a37c9/v8-before.json) and [after](../../../../docs/implementation/v4/evidence/integration-80a37c9/v8-after.json) records are byte-identical.

The [actual-token report](results/declarations-80a37c9/report.json) at clean source `80a37c9` retains the exact [JSON role/content messages](results/declarations-80a37c9/messages.json), tokenizer lockfile hash, source hashes and independently rerun counts. For the local declaration case, complete cold messages including the runtime cost **44,043 cl100k / 43,210 o200k tokens** in TypeScript, **43,424 / 42,701** in Python and **38,461 / 37,693** in Rust. The imported case costs **44,980 / 44,147**, **44,121 / 43,396** and **39,206 / 38,435** respectively. These are explicit local JSON-framed source/runtime/dependency messages, not provider billing or a release ratio. Runtime payload dominates this tiny corpus; the unchanged 4× efficiency requirement is not qualified by it.

This profile closes the null-body gap only. Free type variables without a binder are explicitly rejected, and `old(…)` around nested binders remains outside the executable projection grammar. Full T1-02 semantic coverage and the separate 4× release target remain open.
