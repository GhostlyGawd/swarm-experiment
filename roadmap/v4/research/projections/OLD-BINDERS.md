# Executable projection V10: local binders inside `old(…)`

V10 projects and parses `old(…)` around `ForAll` and `MatchResult` without confusing a local binder with a pre-state capture. Outer variables resolve through the function's saved pre-state; quantifier and Result branch variables keep their local values. The profile reuses V9's explicit trap for unsynthesized declarations. The [tests](../../../../test/projection/old-binders.test.ts) compare actual TS/Python/Rust execution with the Aether reference runtime, including nested quantifiers and a Result branch after the outer input changes.

The [kind completion fixture](corpus-completion.ts) adds valid `Cond`, `ForAll`, `Surface`, `Un` and `Yield` paths absent from the earlier corpus. The [all-kind audit](../../../../test/projection/kind-audit.test.ts) runs exact-root bundles for **45/45** AST node kinds across all three targets, tests the five missing kinds in real target runtimes and explicitly refuses an unbound type variable. The retained [matrix](../../../../docs/implementation/v4/evidence/integration-5a06e42/kind-matrix.json) lists 12 modules, 36 target round trips and no missing kinds.

A detached pre-V10 `8ef1392` checkout and source `5a06e42` emitted byte-identical V9 local/import declaration source, runtime and dependency hashes for all three targets: [before](../../../../docs/implementation/v4/evidence/integration-5a06e42/v9-before.json), [after](../../../../docs/implementation/v4/evidence/integration-5a06e42/v9-after.json).

This is strong representative G1 evidence, not every possible AST context. The executable profile still rejects some valid but restricted host shapes, such as pure calls inside contracts and bindings without an explicit block. The comparable [campaign 13](results/campaign-13-nested-imports/report.json) reports **0.483× cl100k / 0.489× o200k** cold ratios, below the PRD's ≥4× requirement. FR-1.2 itself includes that requirement, so T1-02 and Q03 remain open even though the all-kind matrix passes.
