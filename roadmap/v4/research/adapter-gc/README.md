# Declarative adapter retirement candidate

`SemanticAdapterGarbageCollector` is an opt-in sidecar for a closed Aether module and a signed, lazy declarative adapter table. It removes a registration from a **candidate table** only when the exported, protected, signed-fenced and retained execution closure does not use its capability. Active tasks, replay roots and causally unstable replication roots conservatively keep every capability mentioned by their retained declarations. Audit roots remain pinned without making dead code live.

Each registration names the exact retained AST string containing its JavaScript source, capability, descriptor semantics and SHA-256 artifact identity. Proposal generation constructs a portable dispatch-equivalence certificate. `verify()` reconstructs the liveness and proof obligation independently of proof search; `advance()` additionally requires an admitted signed descendant intent for the exact new table policy and rechecks retention just before publication. The journal is Ed25519-signed and pins historical tables, proposals, proof roots and source bytes. A changed retention snapshot, policy, source artifact, proof or journal fails closed.

The returned snapshot explicitly reports `productionAuthorized: false`. The sidecar does not mutate a production `BrokerEffectRouter`, unload already imported JS or native code, activate a ProcessDeployment artifact, or replace governor promotion. Its source loading path uses the existing exact-byte adapter artifact loader. A full T1-05 admission needs runtime quiescence/unload semantics, all-path dynamic-import analysis and production promotion with rollback. The repository-local Ed25519 signer and source store are trusted for this candidate profile; deletion of both local profile and registry files needs an external recovery anchor.

Focused check: `node --test --experimental-strip-types test/tier1/semantic-gc-adapters.test.ts` (8 cases). The tests include a real before/after effect dispatch, an independent consumer with proof search replaced by a throwing stub, retention arrival before publication, signed lineage refusal, wrong lifecycle, altered liveness, noncanonical signature and journal deletion/corruption.
