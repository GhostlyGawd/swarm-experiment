# Unstable-replication semantic retention (bounded G2 slice)

`DurableTreeWorkspace` accepts an optional `semanticRetention(membershipEpoch)` factory returning `SemanticGcOptions`. The workspace constructs the `SemanticGarbageCollector`; the supplied options must use the **same `DurableGraphStore` instance**, repository ID, and exact membership epoch. Each epoch uses a distinct fixed collector policy. The persisted workspace marker binds the repository, epoch, workspace configuration and real directory, store directory, collector directory/configuration, and retention reference.

For insert and replace, the workspace retains the AST closure in its live store lease, then writes an `unstable-replication` semantic record and physical GC lease **before** authoring the durable operation. Inbound frame ingest follows the same order. Move and delete have no new AST content; their existing epoch content pins remain. A certified checkpoint creates next-epoch base pins before moving the authoritative workspace pointer. Old semantic records and leases are monotone: the existing tree epoch lease may be released after certification, but local ACK, elapsed time, or a new epoch does not release unstable-replication semantic pins.

On reopen, the workspace replays the certified epoch history, derives required roots from each checkpoint's prior base and signed operation cut, and checks every required retention record and physical lease. It checks the current base and frame journal as well. An established marker with a missing lease is checked **before** collector construction, so the collector's ordinary lease reconstruction cannot hide the break. `collectGarbage()` repeats the history/pin checks before the collector sweep. Reopen without the epoch authority, with a changed authority identity, or with a missing/tampered marker, record, or lease fails closed. An authority for the next epoch is required before checkpoint publication.

The collector's `withStableRetentions` fence rejects a retirement decision based on a snapshot taken before a new replication pin. The focused test publishes the pin in a separate process, kills it immediately after frame publication, and confirms that the stale retirement callback does not run. This slice does **not** establish an admission check for a new replication operation whose required adapter was already retired before its pin. Deployment admission must check the live table at that boundary.

Safe release of these pins remains open. It requires a separately proved global causal-stability and audit/replay obligation, not an inferred timeout or local acknowledgment. This bounded slice alone does not verify V4-T1-05/G2 or authorize GC promotion.

Opt in before a workspace has certified history: historical epochs without markers are refused, because a later process cannot prove that their roots remained protected throughout earlier sweeps. The collector's configured record capacity also bounds how many distinct roots can be pinned in an epoch; exhaustion rejects new content operations before their frames are published.

Verification: `node --test --test-concurrency=1 --experimental-strip-types test/tier1/tree-semantic-retention.test.ts test/tier1/tree-workspace.test.ts`, `npm run typecheck`, and `npm run build`.
